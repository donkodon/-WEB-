# SmartMeasure - 採寸撮影用アプリ

商品撮影・採寸データ管理システム。背景白抜き機能（AI）を搭載し、ECサイトへのCSVデータ連携をサポートします。

## 主な機能

- ✅ **Bubbleアプリとの連携** - スマホアプリで撮影した画像を自動同期
- ✅ 商品画像のアップロード・管理
- ✅ **AI自動採寸機能** - Replicate APIによる自動採寸（ランドマーク検出 + cm計算）
- ✅ **ランドマーク手動調整** - Canvas上でドラッグ&ドロップ、Undo/Redo対応
- ✅ **AI背景白抜き処理** - WithoutBG API（無料・高精度）
  - 自動リサイズ（1200×1200px、白背景、中央配置）
  - 個別処理＆一括処理対応
  - リアルタイムUI更新（リロード不要）
  - **マスク画像の自動保存**（白抜き処理時）
- ✅ **マスク編集機能** - Canvas上でマスクを手動編集
  - 🆕 **PNG透明度ベースの自動マスク生成** - 白抜き済み画像から自動で商品部分を検出
  - ブラシツール（商品エリアの追加）
  - 消しゴムツール（背景エリアの追加）
  - 青いマスクオーバーレイ（商品=青、背景=透明）
  - Undo/Redo対応（最大20ステップ）
  - リアルタイムプレビュー
  - 編集したマスクで画像を再生成
- ✅ 画像編集機能（明るさ、色味、WB調整）
- ✅ CSV一括インポート・エクスポート
- ✅ 複数画像の一括ダウンロード（ZIP形式）

## データフロー

```
【①WEBアプリ】CSV登録
    ↓ (D1 Database)
    
【②スマホアプリ(Bubble)】
    ├─ 商品情報追記
    ├─ 商品画像撮影
    └─ Cloudflare R2に保存
    ↓
    
【③WEBアプリ】ログイン時に自動同期
    ├─ R2から画像URL取得
    ├─ SKUコード自動抽出
    └─ D1に自動登録
    ↓
    
【④WEBアプリ】白抜き・編集
```

## Bubbleアプリとの連携設定

### 画像の保存形式

Bubbleアプリから以下の形式で画像が保存されます：

```
URL形式:
https://pub-300562464768499b8fcaee903d0f9861.r2.dev/{ファイル名}

ファイル名形式:
{SKU}_{連番}_{タイムスタンプ}.jpg

例:
https://pub-300562464768499b8fcaee903d0f9861.r2.dev/1025L190003_1_1735592163456.jpg
https://pub-300562464768499b8fcaee903d0f9861.r2.dev/1025L190003_2_1735592164789.jpg
```

### 自動同期

**ログイン時に自動で同期されます：**

1. WEBアプリにログイン
2. R2バケットから画像を自動取得
3. ファイル名からSKUコードを自動抽出
4. D1データベースに自動登録
5. ダッシュボードに反映

**手動同期は不要** - 新しい画像は次回ログイン時に自動で追加されます

### R2バケット連携（オプション - 高速化）

同じCloudflareアカウントでR2バケットを共有する場合：

```jsonc
// wrangler.jsonc
{
  "r2_buckets": [
    {
      "binding": "PRODUCT_IMAGES",
      "bucket_name": "product-images-saisunsatsuei"  // Bubbleアプリと同じバケット
    }
  ]
}
```

**✅ 既に設定済み** - そのまま使えます！

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

#### ローカル開発環境（`.dev.vars`）

```bash
# .dev.vars ファイルを編集
BRIA_API_KEY=your-fal-api-key-here           # Fal.ai APIキー
REPLICATE_API_KEY=your-replicate-api-key     # Replicate APIキー（自動採寸用）
BG_REMOVAL_API_URL=http://127.0.0.1:8000     # セルフホストrembgサーバー
```

#### 本番環境（Cloudflare Pages）

```bash
# BRIA APIキーをシークレットとして設定
npx wrangler pages secret put BRIA_API_KEY --project-name smart-measure

# Replicate APIキーをシークレットとして設定
npx wrangler pages secret put REPLICATE_API_KEY --project-name smart-measure

# 環境変数（wrangler.jsonc に既に設定済み）
# BG_REMOVAL_API_URL は不要（本番ではBRIA APIのみ使用）
```

### 3. APIキーの取得方法

#### BRIA RMBG 2.0 APIキー（背景白抜き用）

**Fal.ai経由でBRIA RMBG 2.0を使用（推奨）：**

1. https://fal.ai/ にアクセス
2. アカウント作成（GitHubまたはGoogle認証）
3. Dashboard → API Keys で新しいキーを作成
4. 生成されたキーを`.dev.vars`にコピー

**料金：** 約$0.0026/画像（従量課金）

#### Replicate APIキー（自動採寸用）

**Replicate API（自動採寸機能）：**

1. https://replicate.com/ にアクセス
2. アカウント作成（GitHubまたはGoogle認証）
3. Account Settings → API Tokens で新しいトークンを作成
4. 生成されたトークンを`.dev.vars`にコピー

**料金：** 約$0.001〜$0.01/画像（モデルによる、従量課金）

## 自動採寸機能の使い方

### 使い方

1. **ダッシュボードで画像を選択**
   - 各画像の左上のチェックボックスをクリック
   - 複数枚まとめて選択可能

2. **「選択画像を自動採寸」ボタンをクリック**
   - 紫色のボタンをクリック
   - 確認ダイアログで「OK」

3. **自動採寸が実行される**
   - Replicate APIが各画像を処理（約8秒/枚）
   - ランドマーク検出 + 基準物（B5用紙）認識 + cm計算

4. **結果が保存される**
   - `product_items` テーブルに保存
   - ランドマーク座標、pixelPerCm、採寸値（cm）を記録
   - 画像に「採寸完了」バッジが表示

### 採寸データの内容

```json
{
  "landmarks": {
    "neck_left_forward": {"x": 707, "y": 266, "conf": 0.84},
    "shoulder_left_top": {"x": 451, "y": 369, "conf": 0.90},
    ...
  },
  "reference": {
    "pixelPerCm": 11.67
  },
  "measurements": {
    "shoulder_width": 43.13,
    "body_length": 68.54,
    "sleeve_length": 60.08,
    "body_width": 46.64
  }
}
```

## 背景削除機能の使い方

### 個別処理

1. **採寸データ画像にホバー**
2. **「白抜き」ボタンをクリック**
3. **自動処理**:
   - 背景削除（WithoutBG API）
   - リサイズ（1200×1200px）
   - 中央配置（白背景）
   - R2へ保存
4. **画像が自動更新**（リロード不要）

### 一括処理

1. **複数の画像をチェック**（通常画像＆採寸データ画像）
2. **「選択画像を白抜き」ボタンをクリック**
3. **バックグラウンドで順次処理**
4. **各画像が完了次第、自動更新**

### 処理仕様

- **使用API**: WithoutBG Focus API（無料）
- **出力サイズ**: 1200×1200px（正方形）
- **背景色**: 白
- **マスク画像**: 自動保存（白=削除、黒=保持）
- **保存先**: R2（`test_company/{sku}/mask_{timestamp}.png`）

## マスク編集機能の使い方

### 画像処理プレビュー内のマスク編集

**マスク編集は画像処理プレビューページの統合機能として利用できます。**

#### アクセス方法

1. **ダッシュボードで任意の画像をクリック**
2. **画像処理プレビューページが開く**
3. **左サイドバーの「手動修正」エリアで「マスク」ボタンをクリック**
4. **マスク編集モードが有効化される**

#### マスク編集パネル（画像処理プレビュー内）

マスクモードを有効にすると、専用の編集パネルが表示されます：

**🆕 自動マスク生成機能（PNG透明度ベース）**
- **白抜き済み画像（_p.png）がある場合**: 
  - **自動で商品部分が青く表示されます** ✅
  - PNG画像の透明度（アルファチャンネル）を解析
  - 不透明なピクセル（alpha > 10）= 商品 = 白マスク = 青表示
  - 透明なピクセル（alpha ≤ 10）= 背景 = 黒マスク = 透明
  - **完璧な精度**: WithoutBG APIの結果を100%活用
  - **メッセージ**: 「✅ 商品が自動選択されました。消しゴムで背景を追加できます。」
- **白抜き前の画像の場合**:
  - 手動モードで開始（全て透明）
  - **メッセージ**: 「⚠️ 自動生成失敗。ブラシで商品を青く塗ってください。」

**🎨 透明背景PNG + 白背景表示**
- **保存形式**: 透明背景PNG（アルファチャンネル付き） ← マスク生成に最適 ✅
- **表示方法**: Canvas上で白背景を合成して表示 ← 編集時の視認性向上 ✅
- **ダウンロード**: 透明背景のまま保存 ← Photoshop等での活用可能 ✅
- **既存画像**: 白背景PNG → 再度白抜き処理が必要（新APIは透明背景を返す）

**青いマスクオーバーレイ（視覚化）**
- **初期状態（白抜き済み）**: 商品部分が**自動的に青く表示**される ✨
- **初期状態（白抜き前）**: 全て透明（青なし）
- **商品エリア**: 濃い青（alpha 180）で表示 = 保持される部分
- **背景エリア**: **透明（オーバーレイなし）** = 削除される部分
- **表示/非表示切替**: チェックボックスでオン/オフ可能
- **リアルタイム更新**: 描画中も青いマスクがリアルタイムで表示
- **直感的**: 青く残った部分が商品として保持される

**ブラシ/消しゴム切替**
- **商品指定（ブラシ）**: 青を塗る → 商品として保持（濃い青で表示）
- **背景指定（消しゴム）**: 青を消す → 背景として削除（透明になる）
- **初期モード**: 消しゴム（背景指定）が選択状態

**ブラシサイズ調整**
- スライダーで5px〜100pxまで調整可能
- リアルタイムでサイズ表示

**Undo/Redo機能**
- 最大20ステップの履歴を保存
- 「元に戻す」「やり直す」ボタンで操作

**プレビュー機能**
- 「プレビュー」ボタンをクリック
- 編集結果を別ウィンドウで確認
- マスク適用後の画像を確認可能

**保存と再生成**
1. **「マスクを保存」ボタンをクリック**
   - 編集したマスク画像をR2に保存（`{company_id}/{sku}/mask_{timestamp}.png`）
   - データベースの`mask_image_url`に保存
2. **再生成確認ダイアログが表示**
   - 「OK」→ 編集したマスクで画像を再生成
   - 画像が更新され、ページリロード

**キャンセル**
- 「キャンセル」ボタンでマスクモードを終了
- 編集内容は破棄されます

### レガシー: 専用マスク編集ページ

採寸データ画像用の専用マスク編集ページも引き続き利用可能：
- URL: `/mask-editor/:sku`
- アクセス: ダッシュボードで「マスク編集」ボタンをクリック（マスク画像がある画像のみ）
   - 「キャンセル」→ マスク画像のみ保存
3. **再生成処理**（クライアント側）
   - 元画像とマスクを合成
   - 1200×1200pxにリサイズ
   - R2に保存
   - ダッシュボードに反映

### マスク編集の仕様

- **マスク形式**: PNG（白=削除、黒=保持）
- **編集モード**: ブラシ/消しゴム
- **履歴**: 最大20ステップ
- **保存先**: R2（`test_company/{sku}/mask_edited_{timestamp}.png`）
- **クライアント側処理**: Canvas APIで高速描画
- **配置**: 中央配置（アスペクト比維持）
- **保存先**: Cloudflare R2
- **URL形式**: `test_company/{sku}/measurement_{timestamp}_p.png`

## トラブルシューティング

### 白抜き処理が失敗する

1. WithoutBG APIの接続を確認
2. 画像URLが有効か確認（Replicate URLは期限切れの可能性）
3. ブラウザコンソールでエラーログを確認（F12）

### 画像が更新されない

1. キャッシュをクリア（Ctrl+Shift+R）
2. 処理が完了するまで待つ（約15秒/枚）
3. ブラウザコンソールで処理ログを確認
